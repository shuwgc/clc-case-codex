# 全域土地综合整治项目组 · 成果发布站

项目首页：https://shuwgc.github.io/clc-case-codex/

本仓库提供成果发布网页，Windows安装包通过GitHub Releases分发。研究说明、软件快照、过去版本与开发日志分别呈现，论文成果按实际进展收录。版本清单中的下载状态、文件大小与SHA-256是安装包核验依据；未上传附件标为待上传。

静态页面为index.html、versions.html、log.html。releases.json记录公开安装包地址、主要改动及历史快照；同号构建保留独立安装包。素材与字体说明见CREDITS.md。

本地审阅与合并前检查见[DEPLOY.md](DEPLOY.md)。

既有案例库Web版保留于[app.html](app.html)，原有案例、政策和资料页面继续使用原静态资源。桌面安装包与Web版能力、版本分别说明。

当前正式版本为1.0.0（2026-10-23）。政策工具统计与创新条目、域外检索口径、案例配图和联系邮箱同步完善，交互必要性计算已修正。历史附件保留对应版本状态，不能自动视为当前论文结论。联系邮箱：shu_terre@163.com。

正式1.0.0与早期同号归档分列，早期安装包仍标为“早期v1.0.0”。0.6.7的三份同号构建分别展示下载入口，历史安装包和快照保留。下载地址及核验状态见releases.json和过去版本页。

Web版的跨站联网聚合检索受浏览器CORS和静态托管限制；联网检索请使用桌面版。Web版站内案例与内置资料检索保留既有功能。
