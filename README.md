# 全域土地综合整治项目组 · 成果发布站

项目首页：https://shuwgc.github.io/clc-case-codex/

本仓库提供成果发布网页，安装包在公开上传并核验后通过GitHub Releases分发；当前未上传的附件明确标为待上传。研究说明、软件快照、过去版本与开发日志分别呈现。论文成果按实际进展收录。

静态页面为index.html、versions.html、log.html。releases.json记录公开安装包地址、主要改动及历史快照；同号构建保留独立安装包。素材与字体说明见CREDITS.md。

本地审阅与合并前检查见[DEPLOY.md](DEPLOY.md)。

既有案例库Web版保留于[app.html](app.html)，原有案例、政策和资料页面继续使用原静态资源。桌面安装包与Web版能力、版本分别说明。

2026-10-21已公开归档并核验19个历史Windows安装包，0.6.6另经过完整下载SHA-256比对。当前版本为0.6.7，下载地址与核验状态见releases.json及过去版本页。

Web版的跨站联网聚合检索受浏览器CORS和静态托管限制；联网检索请使用桌面版。Web版站内案例与内置资料检索保留既有功能。
